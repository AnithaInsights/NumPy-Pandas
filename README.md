# Python Data Analytics – NumPy & Pandas

## 📌 Overview

This assignment focuses on the fundamentals of **NumPy and Pandas** for data analysis using Python.

The assignment covers NumPy array operations, Pandas Series, and Pandas DataFrames, along with data inspection, indexing, slicing, filtering, aggregation, and data manipulation.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Jupyter Notebook / Google Colab

## 📚 Topics Covered

### 1. NumPy

* Creating 1D NumPy arrays
* Inspecting array shape, data type, and size
* Celsius to Fahrenheit conversion
* Finding maximum, minimum, and mean values
* Array indexing and slicing
* Creating and working with 2D arrays
* Extracting rows, columns, and weekend temperatures

### 2. Pandas Series

* Creating a Pandas Series
* Custom indexing
* Integer-based indexing
* `loc` and `iloc`
* Boolean masking
* Updating Series values
* Removing Series entries
* Calculating CGPA

### 3. Pandas DataFrame

Created a transaction dataset containing:

* Transaction ID
* Product Category
* Region
* Amount

Performed:

* DataFrame creation
* Data exploration using `head()` and `tail()`
* Checking shape, columns, and data types
* Column selection
* Row and column slicing using `iloc`
* Conditional filtering
* Value counts
* Finding unique values
* Grouping and calculating mean values
* Updating transaction amounts
* Creating a Discount column
* Removing rows and columns

## 📊 Dataset

The assignment uses sample datasets for:

* Weekly temperature analysis
* Student marks
* Sales transaction analysis
